# 家庭记账微信小程序

一款面向家庭场景的个人财务记账微信小程序，支持多成员记账、资产/负债管理、收支统计、财务目标、房贷计算等功能，数据本地加密存储并支持云同步。

## 功能特性

### 📝 记账
- 支持 **支出 / 收入 / 资产 / 负债** 四种记账类型
- 每笔记录可指定 **记账成员**、**分类**、**日期** 与 **备注**
- 资产记账区分 **流动资产** 与 **非流动资产**，均可绑定具体成员
- 记录支持左滑 **编辑 / 删除**，编辑时自动回退并重算资产金额
- 分类可配置 **默认金额**，记账时自动填充

### 👨‍👩‍👧 成员管理
- 支持添加 / 编辑 / 删除多个家庭成员
- 每个成员拥有独立头像（预设头像或首字）、个人资产与收支
- 支持 **长按拖动排序** 成员顺序
- 删除成员时自动清理其名下记账记录

### 💰 资产与负债
- **流动资产**：按成员管理，等于资产构成 + 收入 − 支出
- **非流动资产**：家庭资产（年金、公积金、房产等），按分类汇总展示
- **负债**：房贷、车贷等
- 资产总览页展示总资产、流动资产、非流动资产、负债构成
- 资产详情页展示资产构成、变动明细与趋势
- 资产设置页可设置成员 **初始金额** 与 **资产快照**

### 📊 统计
- 按 **本月 / 上月 / 全部** 统计收入、支出与结余
- 分类占比 **饼图**（支出 / 收入）
- 各成员收支统计
- 首页总览：总资产、本月/本年新增、资产趋势图、最近记录（按日分组）

### 🎯 财务目标
- 支持 **家庭目标** 与 **个人目标**
- 设置目标名称、目标金额、图标与颜色
- 实时展示当前进度百分比

### 🏠 房贷计算器
- 支持 **公积金贷款 / 商业贷款 / 组合贷款**
- 内置上海最新房贷利率与公积金贷款额度上限
- 支持 **等额本息 / 等额本金** 两种还款方式
- 展示月供、总利息、总还款额、首月还款等明细
- 记忆用户上次输入的利率与贷款金额

### 🗂️ 分类管理
- 支出、收入、流动资产、非流动资产、负债五类分类
- 支持自定义分类（名称 + 图标）与删除
- 分类可设置默认金额

### 🔒 数据安全与同步
- 本地数据使用 **SM4 国密算法加密** 存储
- 支持 **微信云开发** 云数据库同步（多端共享，后写覆盖）
- 断网时自动降级为本地缓存，联网后自动拉取云端权威数据
- 支持 **金额隐藏** 模式，保护隐私

### ⚙️ 自动入账
- 每月自动入账 **公积金**（更新资产余额，不污染最近记录）
- 每月自动入账 **财产收入**

## 技术栈

- **微信小程序**（原生框架，自定义 TabBar）
- **微信云开发**（云数据库同步）
- **SM4 国密加密**（本地数据加密）
- 无第三方 UI 依赖，纯原生组件实现

## 快速开始

1. 使用 **微信开发者工具** 导入本项目
2. 在 `app.js` 中配置你的 **云开发环境 ID**（`wx.cloud.init` 的 `env` 字段）
3. 在微信开发者工具中开通 **云开发**，创建集合 `fb`
4. 编译运行即可

> 说明：云数据库使用单个集合 `fb`，每种数据类型对应一个文档（members、records、categories、assets、asset_records、goals、settings 等）。

## 数据说明

- 所有数据以 **本地缓存为主**，同时同步到云数据库
- 资产变动记录存储 **变动额**（新值 − 旧值），用于最近记录展示与新增统计
- 数据迁移逻辑（公积金、年金、非流动资产等）在初始化时自动执行，保证历史数据兼容
